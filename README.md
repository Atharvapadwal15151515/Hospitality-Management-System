#  Hospitality Management System

##  Overview
The **Hospitality Management System** is a Java-based desktop application designed to simplify hotel operations such as guest management, room booking, billing, and staff tracking.  
It uses **Java (Swing GUI)** for the frontend and **MySQL** for the backend database, ensuring smooth and reliable data handling.

##  Tech Stack
- **Frontend:** Java Swing  
- **Backend:** Java JDBC  
- **Database:** MySQL  
- **IDE Used:** Eclipse
